Lab 3

In this lab, we were tasked with creating a website using Bootstrap. We focused on the responsiveness of the layout and the use of CSS Grid and Flexbox. After we had done this task, we were responsible for editing an existing Boostrap template to test our knowledge of Bootstrap.

Lab 4

In this lab, we created a simple clock using HTML, CSS, and JavaScript. The clock displays the current time and updates every second. The clock is based on local time and the clock hands are smooth and continuous.

Lab 5 - ThreeJS

In this lab, we explored the ThreeJS library to create 3D graphics in the browser and added shadows to the scene and made them interactive with a controller. After this we were tasked to adapt the code into our Lab 3 self made Bootstrap websites.
